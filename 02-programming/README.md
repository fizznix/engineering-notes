## Learning sequence

Choose a language and learn its runtime and memory model, then study testing, debugging, clean code, and concurrency.

## Topics

- Python, Go, Rust, Java, C#, and JavaScript/TypeScript
- Language runtimes and memory management
- Testing and debugging
- Clean code and concurrency
