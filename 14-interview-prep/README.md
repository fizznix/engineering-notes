## Coding interviews: data structures and algorithms

Start with the [coding interview preparation hub](coding-interviews/README.md) for a practical, theory-grounded guide to recognizing problem patterns, choosing data structures, explaining correctness, practicing deliberately, and following a flexible roadmap.

## System design interviews: HLD and LLD

Use the [HLD/LLD interview preparation hub](system-design-interviews/README.md) to understand the difference between architecture and object-level design, follow a flexible roadmap, and practice with the [HLD guide](system-design-interviews/hld-interview-guide.md) and [LLD guide](system-design-interviews/lld-interview-guide.md). The optional [AI/ML system design guide](system-design-interviews/ai-ml-system-design-interviews.md) is a specialization track, not a replacement for backend system design fundamentals.

## Learning sequence

Build fundamentals in programming and algorithms, then practice system design and relevant specialization topics; record reasoning and revisit gaps.
