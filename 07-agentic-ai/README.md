# Agentic AI

[Back to the repository index](../README.md)

Study software systems that use models, tools, state, and orchestration to carry out multi-step tasks.

## Learning sequence

Compare agents with deterministic workflows first; then explore planning, tool use, state and memory, orchestration, evaluation, and reliability.

## Topics

- Agents versus workflows, planning, and tools
- Memory, reflection, state, and orchestration
- Multi-agent systems and interoperability protocols
- Evaluation, reliability, security, and frameworks
