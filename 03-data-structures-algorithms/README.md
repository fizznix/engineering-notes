# Data Structures and Algorithms

[Back to the repository index](../README.md)

Study the structures and problem-solving techniques used to reason about efficient programs.

## Learning sequence

Begin with complexity analysis, arrays, strings, and hashing; progress through trees and graphs, then practice algorithmic patterns and proof of correctness.

## Topics

- Complexity, arrays, strings, hashing, trees, heaps, graphs, tries, and disjoint-set union
- Sorting, searching, recursion, and number theory
- Backtracking, greedy algorithms, and dynamic programming
- Sliding window, two pointers, and problem-solving patterns

Algorithm explanations should cover intuition, correctness, complexity, implementation, edge cases, and tests where applicable.
