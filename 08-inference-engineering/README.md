# Inference Engineering

[Back to the repository index](../README.md)

Understand the systems and optimizations involved in serving machine-learning models efficiently.

## Learning sequence

Learn prefill and decode and their latency metrics, then study memory and KV cache, batching and parallelism, model optimizations, serving, and measurement.

## Topics

- Prefill, decode, TTFT, inter-token latency, and throughput
- KV cache, memory bandwidth, and GPU fundamentals
- Batching, continuous batching, and parallelism
- Quantization, speculative decoding, and prefix caching
- Serving, profiling, benchmarking, and cost optimization
